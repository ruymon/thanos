# astronaut

Run from the repository root:

```bash
./thanos cut samples/astronaut/photo.png --scribbles samples/astronaut/scribbles.png --out astronaut.png
```

The result lands in `astronaut.png` and should match `cutout.png` in this folder.

To scribble it by hand instead, run `./thanos ui` and open `samples/astronaut/photo.png`.
