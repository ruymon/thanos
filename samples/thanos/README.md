# thanos

Run from the repository root:

```bash
./thanos cut samples/thanos/photo.jpg --scribbles samples/thanos/scribbles.png --out thanos.png
```

The result lands in `thanos.png` and should match `cutout.png` in this folder.

To scribble it by hand instead, run `./thanos ui` and open `samples/thanos/photo.jpg`.
